Power over Ethernet (PoE) Project

Worked on: Spring 2026

View Project

Led the software development team in a multidisciplinary project alongside hardware and marketing teams to design and improve a cost-effective Power over Ethernet (PoE) emergency lighting system for building safety applications. The project focused on analyzing limitations of traditional manual lighting systems and improving reliability during emergency situations such as fires.

My team designed and enhanced the system’s backend model server by implementing:

  • Sensor input validation to improve system accuracy and fault tolerance
  • Audit logging for safety-critical actions and event tracking
  • Configurable emergency thresholds for adaptive response behavior
  • Dynamic device management for scalable networked lighting control
  • Persistent state recovery to maintain system continuity after failures
  • Secure user authentication and access control features

Collaborated across teams to align software functionality with hardware integration and project requirements while leading development planning and technical decision-making.
